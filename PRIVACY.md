# Privacy Policy — PiP Subtitle

*Bahasa Indonesia di bawah.*

Last updated: 2 November 2026

PiP Subtitle does not collect, store on a server, sell, or share any data about you.

- **Nothing is collected or sent.** The extension makes no network requests of its own, has no
  analytics or tracking, and loads no remote code. Everything it does happens in your browser.
- **Settings stay on your device.** Display mode, text size, subtitles on/off, automatic PiP and
  language are saved with `chrome.storage.local` on your computer. They are not synced or sent
  anywhere. Removing the extension removes them.
- **Subtitle files stay local.** A `.srt` / `.vtt` file you load in the PiP window is read in the
  browser and never uploaded.
- **Page captions are only read to be shown.** On the page you are watching, the extension reads
  the captions the video player is showing, only to draw them in the Picture-in-Picture window.
  They are not stored or sent.
- **Volume** set in the popup changes the video's own volume on that page; it is not stored.

The permissions it asks for are used only for the feature itself: access to sites so the content
script can find the video and its captions on any site you use it on, `scripting` so the popup
can open PiP in the right frame of the tab, and `storage` for the settings above.

Questions: open an issue in the project repository.

# Kebijakan Privasi — PiP Subtitle

Terakhir diperbarui: 2 November 2026

PiP Subtitle tidak mengumpulkan, menyimpan di server, menjual, atau membagikan data apa pun tentang
kamu.

- **Tidak ada yang dikumpulkan atau dikirim.** Ekstensi ini tidak membuat permintaan jaringan
  sendiri, tidak memakai analitik atau pelacakan, dan tidak memuat kode dari luar. Semuanya
  berjalan di browser kamu.
- **Pengaturan tetap di perangkatmu.** Mode tampilan, ukuran teks, subtitle on/off, PiP otomatis,
  dan bahasa disimpan dengan `chrome.storage.local` di komputermu. Tidak disinkronkan dan tidak
  dikirim ke mana pun. Menghapus ekstensi ikut menghapusnya.
- **File subtitle tetap lokal.** File `.srt` / `.vtt` yang kamu muat di jendela PiP dibaca di
  browser dan tidak pernah diunggah.
- **Teks subtitle halaman hanya dibaca untuk ditampilkan.** Di halaman yang kamu tonton, ekstensi
  membaca subtitle yang sedang ditampilkan player, hanya untuk menggambarnya di jendela
  Picture-in-Picture. Teks itu tidak disimpan dan tidak dikirim.
- **Volume** yang diatur di popup mengubah volume video di halaman itu sendiri; tidak disimpan.

Izin yang diminta hanya dipakai untuk fiturnya: akses ke situs agar content script bisa menemukan
video dan subtitle-nya di situs mana pun kamu memakainya, `scripting` agar popup bisa membuka PiP
di frame yang tepat, dan `storage` untuk pengaturan di atas.

Pertanyaan: buka issue di repositori proyek.
